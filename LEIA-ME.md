# CRTE Conecta 🌐

O **CRTE Conecta** é uma aplicação web leve, eficiente e descentralizada, projetada para aperfeiçoar a gestão pedagógica, o cadastramento e a organização territorial por polos de atendimento na estrutura de formações continuadas da rede pública estadual. 

Desenvolvido no âmbito do **Programa de Desenvolvimento Educacional (PDE · UVPR)** — *Especialização em Gestão de Ambientes de Aprendizagem*, o projeto nasceu de demandas reais identificadas na Coordenação Regional de Tecnologias Educacionais (CRTE) do Núcleo Regional de Educação da Área Metropolitana Norte (**NRE-AMN / SEED-PR**).

---

## 🚀 Principais Características

- **Arquitetura Offline-First:** Opera utilizando o armazenamento local do navegador (`localStorage`). O sistema funciona perfeitamente em locais com restrição de conectividade à internet.
- **Portabilidade Total:** Desenvolvido em tecnologias web padronizadas (HTML5, CSS3 e JavaScript Vanilla), rodando diretamente no client-side, sem necessidade de instalações ou servidores intermediários.
- **Intercâmbio Descentralizado:** Permite a importação e exportação de dados estruturados via arquivos CSV/JSON, além de estar preparado para futuras integrações (como Google Apps Script).
- **Identidade Institucional:** Interface responsiva adaptada estritamente à paleta de cores oficial do Estado do Paraná, incluindo suporte ao *Modo Kiosk* para exibição em painéis e telas grandes.
- **Ambiente de Apoio Integrado:** Biblioteca digital pós-formação voltada para a consulta rápida de materiais pedagógicos pelos cursistas e professores formadores.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Hospedagem:** GitHub Pages
- **Integração de Dados:** Google Forms & Google Sheets (via exportação/importação de CSV)
- **Metodologia de Desenvolvimento:** Engenharia de Prompt e abordagem **C.P.I. (Contexto, Pergunta e Instrução)** com o uso assistido de IA Generativa (ChatGPT e Google Gemini) sob estrita supervisão e governança humana.

## 📦 Como Executar o Projeto

Como o sistema é executado inteiramente no navegador, existem duas formas de utilizá-lo ou testá-lo:

### 1. Acesso Direto (Web)
Você pode acessar a versão demonstrativa pública (com dados fictícios e não sensíveis para preservação da segurança da informação) diretamente pelo link:
👉 [https://github.io](https://github.io)

### 2. Execução Local
Caso queira rodar o projeto na sua máquina de forma offline:
1. Faça o download ou clone este repositório.
2. Certifique-se de que os arquivos estruturais (`index.html`, os scripts `.js` e folhas `.css`) estejam na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abrir a aplicação instantaneamente em qualquer navegador moderno (Chrome, Edge, Safari, Firefox).

## 🤝 Contribuições e Replicabilidade (Open-Source)

Este projeto foi construído utilizando ferramentas gratuitas e de código aberto. Como forma de **retribuição à comunidade educacional e tecnológica**, o código-fonte do CRTE Conecta é 100% aberto. 

Se você atua em outro Núcleo Regional de Educação (NRE) ou em secretarias municipais e deseja adaptar esta ferramenta para a sua realidade regional:
1. Faça um **Fork** deste repositório.
2. Modifique os menus, regras de georroteamento ou a identidade visual conforme a sua necessidade institucional.
3. Sinta-se à vontade para submeter *Pull Requests* com melhorias no algoritmo!
